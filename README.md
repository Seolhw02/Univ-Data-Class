# 심부전 환자 생존 예측

> 임상 데이터 299건으로 심부전 환자의 사망 여부를 예측하는 모델을 만들고, **처음 결과에서 가장 중요한 변수였던 "추적 관찰 기간(time)"이 결과를 미리 반영한 변수(데이터 누수)임을 확인**해 이를 제거한 뒤 교차검증으로 다시 평가한 프로젝트입니다.

## 핵심 요약

- 처음 분석에서는 `time`(추적 관찰 기간)이 가장 중요한 변수(약 38%)로 나왔지만, 이 값은 **사망하면 관찰이 그 시점에 끝나기 때문에 결과가 나온 뒤에야 알 수 있는 정보**입니다. 실제 예측 시점에는 쓸 수 없는 변수라 성능을 부풀립니다.
- `time`을 제외하자 Random Forest의 ROC-AUC가 **0.90 → 0.76**으로 떨어졌습니다. 이 차이가 누수로 인해 과대평가됐던 부분입니다.
- `time`을 제외한 모델에서는 **혈청 크레아티닌, 심박출률(ejection fraction), 나이**가 주요 변수로 나타났습니다.
- 데이터가 적고(299명) 사망 비율이 32%로 불균형하기 때문에, 한 번의 분할 대신 **층화 5겹 교차검증**과 **ROC-AUC·재현율** 중심으로 평가했습니다.

## 배경

심부전은 조기에 위험 환자를 찾아 관리하는 것이 중요한 질환입니다. 이 프로젝트는 12가지 임상 지표로 환자의 사망 여부를 분류하고, 어떤 지표가 위험과 관련 있는지 살펴보는 것을 목표로 했습니다.

## 데이터

- 출처: Kaggle, *Heart Failure Clinical Records Dataset*
- 규모: 환자 299명, 입력 변수 12개, 목표 변수 1개(`DEATH_EVENT`, 사망 = 1)
- 사망 비율: 32.1% (불균형 데이터)
- 변수: 나이, 빈혈, CPK 효소, 당뇨, 심박출률, 고혈압, 혈소판, 혈청 크레아티닌, 혈청 나트륨, 성별, 흡연, 추적 관찰 기간(`time`)

## 분석 과정

### 1. 처음 분석 (수업 발표 버전)

- 8:2로 한 번 나눠 KNN, Decision Tree, Random Forest를 비교했고, Random Forest가 정확도 0.75, 재현율 0.48, F1 0.615로 가장 좋았습니다.
- 변수 중요도 1위는 `time`(약 38%)이었습니다.

### 2. 문제 발견: `time`은 결과를 반영한 변수

`time`은 환자를 얼마나 오래 관찰했는지를 뜻합니다. 사망한 환자는 사망 시점에 관찰이 끝나므로 관찰 기간이 짧을 수밖에 없습니다. 즉 `time`이 짧다는 것은 원인이라기보다 **결과(사망)의 흔적**이고, 환자를 처음 진료하는 시점에는 알 수 없는 값입니다.

![생존/사망별 관찰 기간](images/time_by_outcome.png)

### 3. 수정한 분석

- `time` 변수 제외
- 한 번의 8:2 분할 대신 **층화 5겹 교차검증**(평균 ± 표준편차 보고)
- 사망 비율 불균형을 고려해 `class_weight="balanced"` 적용, **ROC-AUC와 재현율** 중심으로 평가
- 해석이 쉬운 기준 모델로 **로지스틱 회귀** 추가

## 결과

### `time` 포함 여부에 따른 성능 차이

![time 포함/제외 ROC-AUC 비교](images/auc_with_without_time.png)

| 모델 | ROC-AUC (time 포함) | ROC-AUC (time 제외) |
|---|---|---|
| Logistic Regression | 0.877 | 0.769 |
| KNN | 0.751 | 0.674 |
| Decision Tree | 0.725 | 0.627 |
| Random Forest | 0.902 | 0.762 |

모든 모델에서 `time`을 빼면 성능이 크게 떨어졌습니다. 처음 결과의 상당 부분이 누수 변수 덕분이었다는 뜻입니다.

### 수정한 모델의 성능 (`time` 제외, 5겹 교차검증 평균)

| 모델 | 정확도 | 정밀도 | 재현율 | F1 | ROC-AUC |
|---|---|---|---|---|---|
| Logistic Regression | 0.686 | 0.504 | **0.648** | **0.564** | **0.769** |
| KNN | 0.689 | 0.529 | 0.269 | 0.356 | 0.674 |
| Decision Tree | 0.686 | 0.509 | 0.461 | 0.477 | 0.627 |
| Random Forest | **0.729** | **0.605** | 0.429 | 0.492 | 0.762 |

![ROC 곡선](images/roc_no_time.png)

Random Forest는 정확도가 가장 높았지만, 사망 환자를 놓치지 않는 것이 중요한 상황이라면 **재현율이 가장 높은 로지스틱 회귀**가 더 적합할 수 있습니다. ROC-AUC는 두 모델이 비슷했습니다. 어떤 모델이 "좋은지"는 목적(위험 환자를 최대한 찾을지, 오경보를 줄일지)에 따라 달라진다는 점을 확인했습니다.

### 주요 변수 (`time` 제외 Random Forest)

![변수 중요도](images/feature_importance_no_time.png)

혈청 크레아티닌, 심박출률, 나이 순으로 중요도가 높았습니다.

## 배운 점

- 성능이 좋아 보이는 결과일수록 **각 변수가 예측 시점에 실제로 알 수 있는 값인지** 먼저 확인해야 한다는 것을 배웠습니다.
- 데이터가 적을 때는 한 번의 분할 결과가 우연에 크게 좌우될 수 있어, 교차검증과 편차를 함께 보는 것이 중요했습니다.
- 불균형 데이터에서는 정확도만으로 모델을 고르면 사망 환자를 놓치는 모델을 선택할 수 있습니다.

## 한계

- 단일 공개 데이터셋(299명)만 사용했고, 외부 데이터로 검증하지 않았습니다.
- 하이퍼파라미터 튜닝은 하지 않았습니다.
- Random Forest의 기본 변수 중요도(불순도 기반)는 값의 종류가 많은 연속형 변수에 유리하게 나오는 경향이 있어, 해석에 주의가 필요합니다.
- 변수 중요도는 예측에 기여한 정도일 뿐, 원인과 결과 관계를 뜻하지 않습니다.
